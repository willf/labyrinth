Pascal’s Triangle and Florentian Labyrinths

A visual study of combinatorics and devotional geometry.

This shows the relationship between Pascal’s Triangle and labyrinths like Florentius’s. For Pascal’s Triangle, each cell is the sum of the two cells immediately above it and to the right. This turns out to just be the number of ways to choosing k unordered outcomes from N possibilities, represented as ( N k ) .

For Florentian Labyrinths created using a phrase that is len characters long, you create a matrix of n columns, resulting in m rows of “sliding windows.” Notice that the number of “sliding windows” (m) is based on the length of the phrase used; If len is the length of the string, then m=len-n+1. A single path has m+n-2 moves. The number of possible down moves is m-1, so the total number of paths is ( m+n-2 m-1 ) .

Florentius’s labyrinth is a mirrored labyrinth with the string “FLORENTIUM INDIGNUM MEMORARE”. That phrase is 26 letters long, and with m = 7 and n = 20. This is 177,100 paths, which is the value highlighted in the triangle below. Because the labyrinth is mirrored, we have 177,100×2=354,200 total paths through Florentius’s labyrinth. Because the binomial coefficients are symmetric, the same number of paths can be found in the triangle twice — that is, with m = 20 and n = 7.

The number of paths grows very quickly as you increase the number of rows and columns. But you need a few rows or columns! In the triangle below, cells with a reasonable number of paths for a spiritual tool are highlighted with a green border.
